# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-06-22

### Added

- Native Akeyless `SecretProviderFactory` plugin for Starburst Enterprise Platform
- Static, dynamic, and rotated secret resolution via `${akeyless:path:key}` syntax
- Authentication: `access_key`, `api_token`, `jwt`, `aws_iam`, `azure_ad`, `gcp`
- Example `secrets.toml` and catalog properties
- Unit tests and smoke-test scripts ([docs/TESTING.md](docs/TESTING.md))
- Deployable plugin ZIP for `secrets-plugins-dir`

[1.0.0]: https://github.com/akeyless-community/starburst-akeyless-provider/releases/tag/v1.0.0
